# Nikos Mavrapidis — Personal Portfolio

The source code for my personal portfolio, featuring selected work across software engineering, machine learning, systems programming, and product development.

**Live site:** [https://nikosmav.github.io/](https://nikosmav.github.io/)

## Technology

- React 18
- Vite
- GitHub Pages
- GitHub Actions

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

Pushes to `main` are built and deployed automatically to GitHub Pages through [the deployment workflow](.github/workflows/deploy.yml).
